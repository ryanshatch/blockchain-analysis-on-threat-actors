# Tren de Aragua ATM Jackpotting — OFAC TRON Disclosure

**Disclosure:** September 30, 2026. OFAC listed seven TRON identifiers associated with individuals in a Tren de Aragua ATM-jackpotting and laundering network. These are **exchange-hosted deposit addresses attributed to designated individuals**, not a claim that each individual owns a self-hosted wallet or that the exchange's hot wallet is sanctioned by proximity. Treat each exact identifier as a direct sanctions-watch seed. [OFAC action](https://ofac.treasury.gov/recent-actions/20260930) · [TRM analysis](https://www.trmlabs.com/resources/blog/treasury-sanctions-tren-de-aragua-atm-jackpotting-network-including-seven-tron-addresses).
